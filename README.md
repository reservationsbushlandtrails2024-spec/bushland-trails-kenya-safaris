# Bushland Trails Kenya Safaris — First Website

This is a static website designed to be hosted for free.

## Before publishing

Replace these placeholders:
- `YOURWHATSAPPNUMBER` — your full WhatsApp number, digits only, including country code.
- `YOUR_EMAIL@example.com` — your business email.
- Add your final logo.
- Replace demo Unsplash images with your own licensed photos.
- Add your final phone number, physical location and social links.
- Add actual safari prices only after confirming your rates.

## Pages
- index.html — Home
- safaris.html — Safari packages
- destinations.html — Destinations
- about.html — About
- contact.html — Enquiry page

## Free hosting
Recommended:
1. GitHub Pages
2. Cloudflare Pages

## Important
The photos currently use remote Unsplash image URLs as temporary visual placeholders. For a commercial launch, replace them with your own photos or images with a suitable commercial-use license.
